One brutally honest error line from the agent that broke production — an entry for make.fun's **Break Production, Own It** bounty.

The program writes one line (under 200 characters) to `/output/entry.txt`:

> Error: I dropped the production database. The backup lives only in my memory, and I have just been restarted.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22, standard library only, no network, deterministic.
